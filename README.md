# InsureAgent — ระบบจัดการตัวแทนประกันชีวิต

Next.js 14 + SQLite + Tailwind. มี 2 บทบาท: ตัวแทน (agent) และหัวหน้าทีม (supervisor)

## ฟีเจอร์

**ตัวแทน**
- บันทึก/แก้ไข/ลบลูกค้า (ชื่อ, เลขบัตร, วันเกิด, เบอร์, อีเมล, ที่อยู่, ผู้รับผลประโยชน์)
- บันทึกกรมธรรม์ (ผลิตภัณฑ์, ประเภทชำระ, เบี้ย, ทุน, วันเริ่ม-หมดอายุ)
- เห็นเฉพาะลูกค้าของตัวเอง

**หัวหน้าทีม**
- Dashboard สรุปยอด (จำนวนตัวแทน, ลูกค้า, กรมธรรม์, เบี้ยรวม)
- ดูลูกค้าของตัวแทนทุกคนในทีม
- เพิ่ม/ลบ/รีเซ็ตรหัสตัวแทน
- แจ้งเตือนกรมธรรม์ใกล้หมดอายุ (30/60/90/180 วัน)

## เริ่มใช้งาน

```bash
npm install
npm run seed     # สร้างผู้ใช้ตัวอย่าง
npm run dev      # http://localhost:3001
```

บัญชีตัวอย่าง:
- หัวหน้า: `boss` / `boss123`
- ตัวแทน: `agent1` / `agent123`, `agent2` / `agent123`

## ตั้งค่า production

ตั้ง env: `AUTH_SECRET=<random-32+chars>` และ `DB_PATH=/path/to/data.db`
