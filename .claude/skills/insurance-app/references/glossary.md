# Glossary — Thai ↔ English insurance terms

ใช้คำไทยใน UI, คำอังกฤษในชื่อตัวแปร/ตาราง.

| ไทย | English | code identifier |
|---|---|---|
| กรมธรรม์ | policy | `policy`, `policies` |
| ผู้เอาประกัน | insured / policyholder | `insured` |
| ผู้รับผลประโยชน์ | beneficiary | `beneficiary` |
| ผู้ชำระเบี้ย | payer | `payer` |
| ตัวแทน | agent | `agent` |
| หัวหน้าตัวแทน / ผู้จัดการหน่วย | unit manager / supervisor | `supervisor` |
| บริษัทประกัน | insurer / carrier | `carrier` |
| เบี้ยประกัน | premium | `premium` |
| ทุนประกัน | sum insured / face amount | `sum_insured` |
| เบี้ยปีแรก | First Year Premium (FYP) | `fyp` |
| เบี้ยปีต่อ | Renewal Year Premium (RYP) | `ryp` |
| ค่าคอมปีแรก | First Year Commission (FYC) | `fyc` |
| ค่าคอมปีต่อ | Renewal Year Commission (RYC) | `ryc` |
| ค่าคอม | commission | `commission` |
| ระยะพิจารณา | free-look period | `free_look` |
| ระยะผ่อนผัน | grace period | `grace_period` |
| ขาดอายุ | lapsed | `status='lapsed'` |
| ต่ออายุ (กลับมีผล) | reinstatement | `reinstate` |
| ต่ออายุ (ชำระเบี้ยงวดถัดไป) | renewal | `renewal` |
| เวนคืน | surrender | `surrender` |
| มูลค่าเวนคืน | cash surrender value | `cash_value` |
| มูลค่าใช้เงินสำเร็จ | paid-up value | `paid_up_value` |
| สินไหม | claim | `claim` |
| เคลม | claim payout | `claim_payout` |
| ผลิตภัณฑ์ | product | `product` |
| ประกันชีวิตตลอดชีพ | whole life | `whole_life` |
| ประกันชีวิตแบบสะสมทรัพย์ | endowment | `endowment` |
| ประกันชีวิตแบบชั่วระยะเวลา | term life | `term` |
| ประกันชีวิตควบการลงทุน | unit-linked | `unit_linked` |
| ประกันบำนาญ | annuity | `annuity` |
| ประกันสุขภาพ | health insurance | `health` |
| ประกันอุบัติเหตุ | personal accident (PA) | `pa` |
| ประกันโรคร้ายแรง | critical illness (CI) | `ci` |
| สัญญาเพิ่มเติม | rider | `rider` |
| ใบคำขอเอาประกัน | application form | `application` |
| ใบรับเงินชั่วคราว | conditional receipt | `conditional_receipt` |
| ตรวจสุขภาพ | medical exam | `medical_exam` |
| คปภ. | OIC (Office of Insurance Commission) | `oic` |
| สมาคมประกันชีวิตไทย | TLAA | `tlaa` |
| ใบอนุญาตตัวแทน | agent license | `license_no` |
